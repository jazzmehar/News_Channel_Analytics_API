# News Channel Analytics API

A Python-based analytics project for analyzing Indian news channel performance using YouTube views, content details, and time-based analysis.

The project provides **half-hourly, daily, and weekly analytics** for multiple news channels.

## 📊 Analysis Levels

- Half-Hourly Analytics
- Daily Analytics
- Weekly Analytics

## 🛠️ Tech Stack

- Python
- FastAPI
- Pandas
- NumPy
- Plotly
- OpenPyXL
- HTML
- Git & GitHub
